ForgeGraph Studio

School + instrument for agent swarms
ForgeGraph · 2026 agent engineering

A swarm is a team
with a map, not a pile of prompts.

ForgeGraph is how you build products with coding agents: a harness around the model, loops that check real gates, and a graph that says who works, in what order, and when a human must speak. This studio teaches it, then lets you run it.

The three layers
Room

Harness

Sandbox, files as memory, git as state, tools, permissions, traces. Same model, better room — the score moves more than a model bump.

Heartbeat

Loop

Act, hit a real test, revise. Stop when evidence exists. Context resets; progress lives on disk.

Map

Graph

Who runs next, what can run in parallel, where a human interrupts, how you recover after a crash.

Two ways in
New idea

Greenfield

Intake → research → spec → human gate → plan → workers → adversary → verify. The spec is the contract.

Already started

Review, then add

Analyst maps the repo. Gap Detector writes a delta backlog. The swarm only touches those paths.

What a top-tier school for this must have
  • A landing that states the outcome before the controls
  • A path with time, level, and a check per lesson
  • A glossary you can ask in plain language
  • Two recipes: new product and existing repo
  • A simulator that narrates the current node
  • Metrics that explain why they moved
  • Opposing roles: worker writes, adversary breaks
  • A guide that sees the live graph
  • Sample graphs loaded first — never an empty canvas
  • Export of the workflow you designed
