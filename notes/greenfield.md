# Greenfield recipe

1. Write the outcome in one sentence. Add non-goals.
2. Research in parallel, then one spec.
3. Human gate. Approve or rewrite.
4. Planner cuts. Architect names modules.
5. Orchestrator fans out workers. Adversary attacks each slice.
6. Integrator, tester, security, reviewer. Verifier last.

The spec is the contract. Workers do not invent scope.
